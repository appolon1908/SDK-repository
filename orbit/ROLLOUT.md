# Repository rollout

## Authority

`SDK-repository` publishes the immutable package set and schemas first. Consumer pull requests pin every package to the exact authority commit and tarball digest.

## Waves

- **Wave A:** Codestra corporate site and identity surfaces.
- **Wave B:** customer account portals and Codestra product suites.
- **Wave C:** operator/admin applications and supported vendor interfaces.
- **Wave D:** product brands and vertical applications.

A repository is not complete because one screen looks correct. Completion covers every route and state, login/logout, shared header/footer, domains, content/assets, tests, evidence, and rollback. Backend-only and observability repositories are contract-only or legitimate N/A unless they render an operator interface.
